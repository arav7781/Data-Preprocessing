# Data preprocessing

Small Python scripts and notebooks (exported from Colab) on getting raw data ready for modelling.

| File | What |
| --- | --- |
| `fillingmissingvalues.py` | finding and filling missing values with pandas |
| `knnimpuataton.py` | KNN imputation with scikit-learn |
| `fakedata.py` | generating synthetic records with Faker |
| `pd_series.py` | pandas Series basics |
| `webscraping.py` | scraping a web page with requests and BeautifulSoup |
| `FeatureAnalysis.ipynb`, `FeatureAnalysis(ECB).ipynb` | feature distributions, correlations and selection |
